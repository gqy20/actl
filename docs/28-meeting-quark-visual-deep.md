### 搜索为何上轮没有刷新

同一画面有两个输入面：

- 网页内 Edit：名称为“搜网盘、搜全网或输入网址（Ctrl + F）”。上轮对它写值成功，结果未随换词更新。
- 原生地址栏 Edit：AutomationId 为 **view_1012**。本轮点击可见搜索框或按 Ctrl+F 后，
  focused_element 指向它，同时弹出“搜索网盘/当前文件夹/搜索全网”建议层。

本轮有效路径是：**真实聚焦 → 核对建议层及搜索范围 → 输入 → Enter → 等待结果完成 → 核对路由和内容**。
Ctrl+F 本身可用；上轮随后对另一个 Edit 执行 type，不能据此断言快捷键无效。
输入框值、建议层、结果路由是三个不同状态，必须分别验证。

## 对适配基建的直接要求

1. **输入面必须验证焦点及状态**：同名/相似输入框不能只用写值成功验收。
2. **读状态允许收敛，写动作不能盲重试**：本轮多次立即快照落后于画面，稳定后能正常读回。
3. **独立窗口和附属弹窗分别识别**：详情、预览、下载目录框的归属各不同；缺少绑定就停当前动作。
4. **混合路线写进 pack**：菜单可走语义定位，时间选项和无标签按钮可走截图点击；不要因 UIA 缺项放弃业务。
5. **结果断言包含路由、范围和业务内容**：原生地址栏值、网页输入值与结果页必须一致。
