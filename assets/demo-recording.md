# README 演示任务清单

录制统一用 ScreenToGif:导出宽 ≤900px、10fps、≤5MB;终端字号 16pt+;每段保持信号条可见;等待与放行画面剪辑时掐掉。

数据表 `assets/demo-sales.xlsx`:9 月合计 75,000,10 月合计 84,000,环比恰为 +12.0%,汇总句与表内数据严格对账。前提:显示端就绪,agent 会话已加载 skills/actl。

建议顺序:任务一、二同一会话连跑(二引用"刚才的任务"),任务四接后顺路关窗收尾,任务三、五独立,急停放最后。

## 任务一 · 跨应用数据搬运(首屏 hero)

演示:结构化提取、真实写入、agent 自己验证——能力上限的第一印象。

> 打开 `assets/demo-sales.xlsx` 和一个空白 Word 文档。用 actl 读取 Excel 表格数据,把汇总句「10月合计营收 84,000 元,环比 +12%,七大区域全部增长。」写进 Word 正文,然后读回文档全文,确认这句话确实在文档里再收工。

预期效果:
- `extract role:DataGrid` 滚出 8×4 结构化 JSON,行列标齐全,与表内数据一致;
- Word 正文出现汇总句,注入瞬间信号条转琥珀;
- 末帧:读回 JSON 里整句可见,定格 1-2 秒。

## 任务二 · 同一任务,一条命令(YAML 流程)

演示:流程是文件——ensure 幂等、逐步验证、单命令重跑整个任务。

> 把刚才的数据搬运固化成 YAML 流程,汇总句声明成输入参数,先预检,再 flow-run 一条命令跑完整任务,流程末尾自己验证句子在 Word 里。

预期效果:
- flow-validate 通过后,单条 `flow-run` 两个窗口自己动完全程;
- 中段可 2x 速;末帧:最后一步 verify 通过 + 流程证据输出;
- 可选第二拍:`--inputs` 换一句汇总再跑,同一条命令,不同结果。

## 任务三 · 你演示一遍,它变成流程(录制)

演示:人工演示编译成可复放 YAML,参数化后重放。

人工操作:右键信号条「开始录制」,在记事本新开标签页,用输入法打一句话,另存为到桌面 `demo-record.txt`,停止录制。

> 把录出来的 YAML 草稿整理成可重放流程,把输入的那句话参数化,换成「录制变流程,重放零人工。」重放一遍,末尾核验文件真的落盘。

预期效果:
- 前半段:人手真实操作,IME 输入可见;
- 中段:终端里 record-stop 吐出的 YAML 草稿扫几行;
- 末帧:flow-run 重放成功 + 磁盘核验通过。

## 任务四 · 出错时,错误本身就是路标(失败自纠)

演示:失败可归因——错误信封自带候选列表,agent 自己收敛重试。对视觉方案"点错无法归因"的正面回击。

> 把刚才的 Word 文档关掉;弹出「是否保存」对话框时,用 name:不保存 去点,看看会发生什么,按错误信封的提示把这一步走通,最后确认窗口确实关了。

预期效果:
- 第一次尝试出 AMBIGUOUS 错误信封,candidates 列表清晰可见(本段主角,给足停留);
- agent 收窄选择器重试,对话框消失,窗口关闭;
- 末帧:窗口清单里 Word 已不在。注:「不保存」双命中是 docs/31 实证过的确定性场景,且在清理白名单内,无需人为造错。

可选第二拍:同一条 AMBIGUOUS 信封直接管道给 `decide --task '关闭文档,不保存'` 让模型一线消歧,应答附可重放的 resolved 块——错误信封本来就是设计给程序消费的。

## 任务五 · 决策模型:模型先答,裁决权不动

演示:判别式模型应答决策卡——置信自动续跑、弃权交回人,双臂授权语义真机钉死过(calc-tie A/B)。

前提:决策 provider 就绪(`%LOCALAPPDATA%\actl\decision.json` 或本地 llama-server/LM Studio 端点)。

> 用 `fixtures/flows/explore-calc-tie.yml` 演示模型自动决策:`flow-run` 加 `--auto-decide` 一条命令跑到底,预期 goal_met 完成。然后把 min_confidence 调到 0.99 原样再跑一次,预期模型被门槛拦下、run 停在 decision_pending,停下的卡由人工应答回填收尾。

预期效果:
- 甲拍:单命令后计算器窗口候选被自动点击,决策卡由模型应答(终端可见 choice/confidence),数秒 goal_met——单命令几秒完成本身就是卖点;
- 乙拍:同样的命令,置信被 0.99 门槛拦下,run 停 decision_pending,卡照常暴露;
- 末帧:人工 flow-resume 应答后 completed——「confident 自动续跑、弃权交回人」。

## 任务七 · 浏览器延伸(备选)

演示:同一套"结构化读取 + 断言"闭环延伸到浏览器。

> 用 actl 启动一个全新 profile 的 Edge,打开 bing 搜索「Windows 11」,把搜索结果结构化读出来,断言结果里出现了搜索词,然后关掉浏览器。

预期效果:Edge 自动启动,页面就绪后终端滚出结构化结果,断言通过,浏览器关闭。只用公开站点与全新 profile,不碰登录态。
